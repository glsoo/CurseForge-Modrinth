# CurseForge for Modrinth

A [Rinthify](https://github.com/glsoo/rinthify) plugin that adds CurseForge to the Modrinth App. Browse and install
mods, modpacks, resource packs, shaders and data packs, with the same pages and version filters Modrinth uses.

## install

1. Install Rinthify
2. In settings > plugins, paste `glsoo/CurseForge-Modrinth` and click install (or download this repo as a zip and
   click zip file)
3. Turn it on and add a CurseForge API key in its settings. You can get one at
   [console.curseforge.com](https://console.curseforge.com)
